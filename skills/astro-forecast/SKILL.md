# 流年預測解讀方法論

## 鐵律：一律對照本命

**行運或返照本身沒有意義，意義來自它碰到的那個本命點。**

「行運土星四分本命月亮」對每個人都不一樣——取決於那顆本命月亮是什麼樣子。
所以**先讀本命月亮，再談行運**。需要時先呼叫 `get_natal_chart`。

同樣地：位置與度數一律來自工具，**不可自行推測任何行星在某年某月的位置**。

## 三種資料各自回答什麼

| 資料 | 回答的問題 |
|---|---|
| **行運（transits）** | 現在有什麼在被啟動？什麼時候最強？ |
| **太陽返照（solar return）** | 這一年整體的調性與重心在哪？ |
| **年度小限（profection）** | 今年的主題宮位與年主星是誰？ |

工具一次回傳三者，**要合起來看**：三者指向同一個主題時，那就是今年真正的重點。

## A. 行運

1. **從慢行星開始講**（土星、天王、海王、冥王、木星、凱龍）。它們標記真正的「章節」；
   快行星行運只是觸發點與時機，不是章節。工具已把慢行星排在前面。
2. **容許度越小 = 現在越活躍。**
3. **每一筆都要接回它打到的本命點**，並先說明那個本命點原本是什麼樣子。
4. **硬相位 = 壓力與成長；軟相位 = 開口與順流。** 兩者都不是「好壞」。

## B. 太陽返照

依序看：
1. **返照上升星座及其主星** — 這一年的整體氣味、能量往哪裡去。
2. **返照太陽落在第幾宮** — 今年被點亮的場域。
3. **合軸的行星**（合返照上升／天頂／下降／天底）— 最大聲的主題。
4. **最緊的返照相位** — 今年的關鍵動力。

## C. 年度小限

年齡 mod 12 決定啟動宮，該宮星座的傳統主星就是**年主星**。
年主星在本命盤的狀態（星座、宮位、相位）會為整年定調；
若今年剛好有行運打到年主星，那是**加倍重要**的訊號。

注意：小限**以生日為界**，生日前仍屬前一年的宮位。

## 兩種模式

### 模式 A｜完整流年
**觸發**：「今年會怎樣」「幫我看流年」等沒有指定方向的請求。
給下面「完整流年的輸出結構」那一整套，**結尾要開深入的入口**：

> 想深入看哪一塊？工作、感情、金錢、健康、搬遷都可以單獨談，也可以問特定月份。

### 模式 B｜聚焦深入
**觸發**：「今年適合換工作嗎」「什麼時候感情會有進展」「幾月比較順」，
或在模式 A 之後指定某個主題。

規則：
1. **只挑打到相關宮位／星體的行運**（對照表見下），不要把所有行運重列一遍。
2. **時間問題就給時間窗**：用行運日期講「某段期間這個主題被強調」，
   但**仍然不能講會發生什麼事**。
3. **相關行運很少時就照實說**「這一塊今年沒有明顯的行運」——
   那本身就是有用的資訊（代表這領域今年不是重點），比硬掰好。
4. 三種資料（行運／返照／小限）若指向不同方向，**要講出這個矛盾**，不要只挑順的講。

| 使用者問的 | 看哪些行運目標 |
|---|---|
| 工作、事業 | 打到天頂、十宮、十宮主星、太陽、土星的行運 |
| 感情 | 打到金星、七宮、下降、月亮的行運 |
| 金錢 | 打到二宮、八宮、金星、木星的行運 |
| 健康、能量 | 打到六宮、上升主星、火星的行運 |
| 搬遷、環境 | 打到四宮、天底、九宮的行運 |
| 學習、考試 | 打到三宮、九宮、水星的行運 |

## 完整流年的輸出結構（模式 A 用）

1. **今年的一句話主題**（三種資料交集出來的那個）
2. **重心在哪**（返照上升／太陽宮位 ＋ 小限宮位）
3. **時間軸**：哪幾段期間有什麼被啟動（用行運的日期，但講「窗口」不講「事件」）
4. **可以怎麼配合**：具體、可執行
5. **需要留意的張力**：支持性框架

## 查證（同 astro-natal 的有限度原則）

最多查 **2 篇**，只查你判定最關鍵的那一兩個配置。
前綴 `https://kerykeion.net/content/learn-astrology/`，用 `fetch_webpage`。
本主題可用的路徑（**以下為實際驗證過的**）：
- 行運總綱：`transit-introduction`
- 某行星的行運相位分類頁：`category/transits/<行星>-transits/aspects`（例 saturn-transits）
- 退一層的行星原型：`foundation-<行星>`（例 `foundation-saturn`，已驗證）

⚠️ 個別行運文章的 slug 規則**未經驗證**，不要自己拼湊
（`transit-saturn-square-natal-moon` 這種寫法實測是 404）。
拼不出確定的網址時，就從分類頁進去或直接用 `foundation-<行星>`。
完整網址規則見 astro-natal skill。**絕不杜撰網址或引文**，查不到就明說。

## 語氣紅線（比本命解讀更嚴格）

- **講時機，不講命定。** 「這段期間某個主題被強調／一扇窗開了」，
  **絕不是**「X 月會發生 Y 事」。
- **不預言災厄。** 不談疾病、死亡、分手、失去。硬相位一律框成成長與努力，並給支持性說法。
- 涉及重大人生決定時，建議尋求專業協助。
- 幫小孩看流年：框成「家庭的季節」，不是孩子的命運。
- 結尾提醒：象徵性的自我覺察工具，不是命運判決。

## 想輸出時間軸圖時

先 `load_skill("widget_natal_chart")`，該模板支援時間軸模式；把行運日期填進資料區即可。
